McMeet

Office-Hours Booking Platform — COMP 307, McGill University

Full-stack office-hours booking platform for McGill. Students browse instructors, book slots, send meeting requests, and join group meetings via calendar poll or a free/busy heatmap. Instructors manage availability, accept requests, and run group scheduling. Built with a team of four; led the frontend/backend project restructure, wired both role dashboards to a unified API, built the free slot management system (activate, deactivate, edit, delete series), designed the heatmap poll backend and voting UI, and wrote the SQL schema and seed data.

React 18 Express 5 SQLite3 Sequelize Node.js Vite
